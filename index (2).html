Build notes

        
Deliberate choices a recruiter can look for in the source.

        
Table-based layout
Nested <table> with role="presentation" — the only layout method Outlook renders reliably.

        
Inline styles
Every style is inline; a <head> block is backup only, since several clients strip it.

        
Bulletproof button
A padded, coloured link with a VML fallback so the CTA still fills and clicks in Outlook.

        
Preheader text
Hidden preview line that controls the inbox snippet instead of leaking stray markup.

        
Accessibility
Semantic lang, real contrast, a logical reading order and role="presentation" so screen readers skip the layout grid — fitting for a mobility audience.

        
Dark-mode aware
color-scheme + prefers-color-scheme so the template holds up in dark inboxes.
